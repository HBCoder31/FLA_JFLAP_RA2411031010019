# FLA JFLAP Assignment

This folder contains JFLAP 7.1 files for the Finite Automata, Pushdown Automata and Turing Machine questions.

## Files

| File | Question | Machine type | Description |
|---|---|---|---|
| `Q1_DFA.jff` | 1 | Finite automaton (DFA) | Accepts strings over {0, 1} with an even number of 0s |
| `Q2_NFA.jff` | 2 | Finite automaton (NFA) | Accepts strings over {a, b} that end in `ab` |
| `Q3_PDA.jff` | 3 | Pushdown automaton (final state) | Accepts aⁿbᵐcⁿ with n ≥ 1 and m even |
| `Q4_PDA.jff` | 4 | Pushdown automaton (final state) | Accepts strings over {0, 1} in which the number of 0s is exactly twice the number of 1s |
| `Q5_TM.jff` | 5 | Standard Turing machine | Accepts aⁿbⁿ with n ≥ 1 |

## Design notes

**Q1 (DFA).** Two states. q0 (start, final) means an even number of 0s has been read so far. q1 means an odd number. Reading 0 switches between the two states, and reading 1 keeps the current state.

**Q2 (NFA).** States q0 (start), q1, and q2 (final). q0 loops on a and b. On reading a, the machine can also guess that the final `ab` is starting and move to q1. From q1, reading b moves to q2. This is nondeterministic, because q0 has two transitions on a.

**Q3 (PDA).** The stack counts the a's. States q1 and q2 track whether the number of b's is odd or even. Each c pops one a, and q4 is reached only when the stack holds just the bottom marker Z. The empty string and m = 0 are accepted.

**Q4 (PDA).** The stack holds X for each surplus 0 and D for each deficit. A 1 subtracts two from the balance, which takes two steps through state q1. Acceptance requires the balance to be zero and the stack to contain only Z.

**Q5 (TM).** The machine repeatedly marks the leftmost a with X, scans right to find an unmarked b, and marks it with Y. It returns to the start and repeats. If a b is left over after all a's are matched, or a b is missing, the machine rejects. Otherwise it accepts when the tape holds only X's and Y's followed by blanks. The symbol `B` is the blank.

## Test strings

**Q1:** Accept ε, `11`, `00`, `0110`. Reject `0`, `1`, `010`.

**Q2:** Accept `ab`, `aab`, `bab`. Reject `aba`, `b`, ε.

**Q3:** Accept `ac`, `abbc`, `aabbcc`. Reject `abc`.

**Q4:** Accept `001`, `010`, `100`, ε. Reject `01`, `0`, `10`, `0100`.

**Q5:** Accept `ab`, `aabb`, `aaabbb`. Reject `aab`, `abb`, `ba`, ε.



## How to check the files

Open each `.jff` file in JFLAP 7.1 and run the test strings with Input → Multiple Run. The files were generated by hand, so confirm each one loads before submitting.
